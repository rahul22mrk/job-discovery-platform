# Unique Value Proposition

## What We Want to Solve

There are already many websites and apps that list jobs and walk-in drives.

The goal of this product is not to become another website with a large number of job listings.

The goal is to make job discovery easier, cleaner, and more reliable.

## What Makes It Different

### 1. Discover From Multiple Sources

The platform will look for relevant opportunities across multiple publicly accessible sources instead of depending on a single website.

### 2. Less Duplicate Data

The same hiring opportunity can appear on multiple websites.

The platform should try to identify such duplicates and show them as one opportunity.

### 3. Fresh Information

Walk-in information can become outdated quickly.

The platform should track when an opportunity was discovered and when it was last checked.

Expired opportunities should not continue to appear as active results.

### 4. Source Transparency

Every opportunity should have a source.

Users should be able to open the original source and verify the information themselves.

### 5. Simple Search

Users should not have to use complicated search queries.

The initial search should be simple:

- City
- Technology / Role
- Experience
- Date range

Predefined options can help improve search results, while custom keywords should also be supported.

### 6. Relevant Results

The platform should focus on useful opportunities instead of showing a large number of loosely related results.

For example:

A search for:

Java + Bengaluru

should prioritize relevant Java opportunities in Bengaluru instead of showing every job that happens to mention Java.

## Trust

Trust is an important part of the product.

The platform should not claim that a job is verified unless there is enough information to support that claim.

Where possible, the product should show useful signals such as:

- Source
- Last checked time
- Event date
- Location
- Application link
- Whether the opportunity was found on multiple sources

If information cannot be confirmed, the product should make that clear.

## Product Philosophy

The product should follow a simple principle:

> Show fewer useful opportunities rather than many unreliable ones.

The main focus is:

**Relevance + Freshness + Transparency + Simplicity**

## V1 Focus

For V1, these principles will be applied to upcoming walk-in drives.

The same foundation should later support other types of job discovery without changing the core idea.
